# Ghostwriter 👻
A Chrome extension whose ghost whispers your next words in real textboxes. Starts as normal autocomplete, grows uncanny.

## Install
chrome://extensions -> Developer mode -> Load unpacked -> select this folder.
Open Options, paste a Groq or Gemini API key, press "Test API".

## Use
Open a site (Gmail compose, X, any textarea) -> click the icon -> "Haunt this site" -> type 12+ chars and pause.

## Horror
At stage 2+ the ghost may turn the lights off: a 6-second flickering blackout, a figure creeping closer, a heartbeat, one line. Never gory. Any key or Esc ends it. Reduced-motion users never see it.

## Safety
- Opt-in per site; nothing runs elsewhere (no reads, no sends).
- Overlay only: it never types, inserts or deletes anything.
- Password / card / OTP fields are skipped.
- Memory is opt-in, local, clearable.

## Privacy
The last 300 characters before your caret on a haunted site are sent to your chosen AI provider using your own API key.

## Exorcise
Any key hides the ghost and ends a blackout. Esc x3 = global off. Popup toggle, "Banish from this site", "Clear memories", or uninstall.
